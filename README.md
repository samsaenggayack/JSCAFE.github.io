# JSCAFE 질의응답 / 배경 / 그라데이션 업데이트

변경사항

- 사이트에 남아 있던 `Q&A` 문구를 `질의응답`으로 통일
- Pages CMS 메뉴도 `Q&A` → `질의응답`
- 문의 챗봇:
  - 등록된 질의응답을 기준으로 답변
  - 참고 질의응답 표기
- 상단 배경 이미지:
  - 이미지 원본 비율 전체 표시
  - 하단 페이드 제거
  - 본문 카드가 이미지 위로 겹치지 않음
  - PC / 모바일 모두 잘리지 않음
- 금색 + 푸른색 그라데이션 방향을 `금색 → 푸른색`으로 변경
- 일정 날짜는 계속 `날짜 (직접 입력)` 일반 텍스트 필드 사용

## GitHub 덮어쓰기

저장소 최상단:
- index.html
- style.css
- app.js
- fallback-data.js
- .pages.yml

`data` 폴더 안:
- faq.json
- site.json

※ faq.json을 Pages CMS에서 이미 많이 수정했다면, 기존 파일을 먼저 백업해두는 것을 권장합니다.

## 음원 연결

가능합니다. MP3 파일을 보내주면 사이트에 작은 재생/일시정지 버튼을 추가할 수 있습니다.
브라우저 정책 때문에 소리가 있는 자동재생은 보통 차단되므로, 방문자가 재생 버튼을 한 번 누르는 방식이 가장 안정적입니다.
