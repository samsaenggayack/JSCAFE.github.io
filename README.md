# JSCAFE D-DAY + 눈 내리기 업데이트

## 추가 기능

### D-DAY
- 기준일: `2027-12-17`
- 행사 전: `D-숫자`
- 행사 당일: `D-DAY`
- 행사 후: `D+숫자`
- Pages CMS → 사이트 설정 → `디데이 기준 날짜`에서 직접 수정 가능
- 입력 형식: `YYYY-MM-DD`

### 눈 내리기
전달해준 스킨에서 사용하던 `magic-snowflakes` 효과를 그대로 분리해 적용했습니다.

- 색상: `#99bde8`
- 눈 개수: `10`
- 최소 투명도: `0.2`
- 최대 투명도: `0.5`
