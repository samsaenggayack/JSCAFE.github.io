# JSCAFE 로고/모바일/CMS 입력 업데이트

이번 수정사항

1. 상단 로고 이미지
   - `background-size: cover` 방식 제거
   - 실제 이미지 태그로 표시
   - PC와 모바일 모두 원본 비율을 유지하여 이미지 전체가 보입니다.

2. 모바일 대응
   - 상단 로고 이미지 자동 축소
   - 메뉴 가로 스크롤
   - 본문/검색창/카드 크기 조정
   - 문의 챗봇을 모바일 화면 안에 맞게 표시

3. 중앙 바로가기 카드
   - ❓ / ꕥ / ◈ 등의 장식 로고 전부 제거

4. 왼쪽 사이드바
   - CONTACT → 메일
   - 2027jscafe@gmail.com 표시

5. 문의 챗봇
   - `Q&A` 표기를 `질의응답`으로 변경
   - `등록된 질의응답을 기준으로...`
   - `참고 질의응답 · ...`

6. Pages CMS 일정 날짜
   - 달력(date) 필드 제거
   - `string` 일반 텍스트 필드로 변경
   - 라벨: `날짜 (직접 입력)`
   - 예: `2027.12.18`, `2027년 12월`, `12월 중`, `미정`
   - 날짜를 비워도 저장할 수 있습니다.

## GitHub에 덮어쓸 파일

저장소 최상단에 다음 4개를 덮어쓰세요.

- index.html
- style.css
- app.js
- .pages.yml

데이터 JSON 파일은 수정할 필요가 없습니다.

## Pages CMS가 여전히 달력으로 보일 때

`.pages.yml`을 저장소 최상단에 덮어쓴 뒤 Pages CMS에서 저장소를 나갔다 다시 열거나
브라우저에서 Ctrl+F5로 강력 새로고침하세요.

새 설정이 읽히면 일정 항목의 라벨이
`날짜 (직접 입력)`으로 표시되고 달력 아이콘이 없어집니다.
