# JSCAFE 일정 직접입력 + 챗봇 아이콘 업데이트

변경사항

- Pages CMS 일정의 `날짜`가 달력 선택이 아니라 **직접 입력 칸**으로 변경되었습니다.
- 다음처럼 자유롭게 입력할 수 있습니다.
  - `2027.12.18`
  - `2027년 12월 18일`
  - `12월 중`
  - `미정`
- 날짜가 비어 있으면 사이트에서는 자동으로 `미정`으로 표시됩니다.
- 일정은 이제 날짜 텍스트로 자동 정렬하지 않고 **CMS에 저장된 순서대로** 표시됩니다.
- 오른쪽 아래 챗봇 버튼의 `문의` 글자를 없애고 `❓` 아이콘으로 변경했습니다.

## GitHub 덮어쓰기

저장소 최상단에서 아래 파일만 덮어쓰면 됩니다.

- `.pages.yml`
- `app.js`
- `index.html`
- `style.css`

기존 Q&A, 협력물, 일정 데이터 파일은 건드리지 않아도 됩니다.


## 글꼴 변경

사이트 전체 글꼴을 `Noto Sans KR`로 통일했습니다.

- 본문
- 메뉴
- Q&A
- 일정
- 협력물
- 공지
- 챗봇
- 메인 제목

웹폰트를 사용하므로 방문자의 기기에 폰트가 설치되어 있지 않아도 동일하게 표시됩니다.

### GitHub에 덮어쓸 파일

이번 변경에서는 `style.css`만 덮어써도 됩니다.


## 사이드바/섹션명 업데이트

- 사이드바 기호:
  - 一 전체보기
  - 二 자주 묻는 질문
  - 三 협력물
  - 四 일정
- 챗봇 버튼은 `❓` 유지
- 섹션 상단 작은 문구:
  - 질의응답
  - 협력
  - 타임라인
