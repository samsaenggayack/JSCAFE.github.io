## 행사 운영 위젯 추가

### 행사 준비 진행사항
Pages CMS의 `행사 준비 진행사항` 메뉴에서 각 항목의 `완료` 토글을 직접 켜거나 끌 수 있습니다.
완료 개수와 진행 막대가 공개 사이트에 자동 반영됩니다.

기본 항목:
- 1차 수요조사
- 협력물 공개
- 예약폼 공개
- 상세 장소 공개
- 행사 개최

항목 자체를 추가하거나 제목을 바꾸는 것도 가능합니다.

### 장소 안내
Pages CMS의 `장소 안내` 메뉴에서 아래 내용을 수정할 수 있습니다.
- 장소 공개 상태
- 지역
- 장소명
- 주소
- 안내 문구
- 지도/길찾기 링크

지도 링크가 비어 있으면 사이트의 `지도 보기` 버튼은 자동으로 숨겨집니다.

### 일정 저장
일정 페이지에 `＋ 일정 저장` 버튼을 추가했습니다.
현재 행사 시작일/종료일인 2027-12-18~2027-12-19를 한 번에 담은
`samsaenggayak-2027.ics` 파일을 생성합니다.
휴대폰이나 PC의 캘린더 앱에 등록할 수 있습니다.
