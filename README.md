# 三生佳約 Pages CMS 운영 버전

이 ZIP은 **GitHub Pages + Pages CMS**용입니다.

## 처음 한 번만 하면 되는 설정

1. GitHub에서 새 Public 저장소를 만듭니다.
2. 이 ZIP의 내용물을 전부 저장소 최상단에 업로드합니다.
3. GitHub 저장소 → Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main`, Folder: `/(root)` → Save
6. 잠시 뒤 GitHub Pages 주소가 생성됩니다.

## 관리 화면 연결

1. https://app.pagescms.org/ 접속
2. GitHub로 로그인
3. Pages CMS GitHub App 설치
4. 이 사이트 저장소 접근 권한 허용
5. 저장소를 열면 `.pages.yml`을 읽어서 관리 화면이 자동 생성됩니다.

## 관리 화면에서 직접 수정 가능한 것

- 사이트 제목 / 메인 안내문
- 문의 이메일
- 상단 배경 이미지
- 포인트 색상 / 배경색 / 상단 이미지 높이
- 공지 / 게시물
- Q&A / 챗봇 검색 키워드
- 참여진
- 일정

Pages CMS에서 저장하면 GitHub에 반영되고, GitHub Pages 사이트도 자동 갱신됩니다.
